> **Z1** of the S-series. Produced 2026-05-26 against HEAD `3f8dead`. Pair with [`web-feature-matrix-2026-05-26.md`](web-feature-matrix-2026-05-26.md) (C0, pending) + [`admin-2026-05-26.md`](admin-2026-05-26.md) (Z2, pending).

## Verdict — **~45% complete** (functional alpha, three ship-blockers)

The scaffold is architecturally sound: Expo Router file-based routing, isolated workspace install (Expo 51 / React 18.2 pinned out of root per `pnpm-workspace.yaml` line `'!apps/mobile'`), `@app/sdk` consumed via `link:` symlink, Tamagui theming, React-Query with AsyncStorage persistence (24h offline TTL), deep-link support (custom scheme + universal links). Six screens render real API data via generated SDK hooks. Auth (password + magic-link) works end-to-end.

But three gaps block shipping:

1. **Tokens in plaintext AsyncStorage** — `lib/sdk.ts` explicitly admits this and flags `expo-secure-store` as the swap. CLAUDE.md rule 12 says access-tokens-in-memory only; mobile complies at runtime but persists unencrypted across reboots. **D1 fixes this; it is the gating slice.**
2. **Explore tab is three buttons that open `https://travelsuperapp.local`** — ~10% complete. No `expo-location`, no maps, no near-me, no federated places. **D2.**
3. **Memory-book detail renders asset position + id, not images** — assets returned from API are missing `imageUrl` / `imageKey` projection on the mobile path (or the screen doesn't read it). No upload, reorder, or theme picker either. **D3.**

Zero native integrations beyond `@react-native-async-storage/async-storage` (1.23.1) + `@react-native-community/netinfo` (11.3.1). No `expo-secure-store`, no `expo-notifications`, no `expo-location`, no `expo-camera`, no `expo-image-picker`, no `expo-haptics`. No tests of any kind. No `eas.json`. No `.env.example`.

The code itself contains **zero in-line `TODO` / `FIXME`** — every deferral is a JSDoc note referencing the prompt that punted it. That's good hygiene, but the deferrals add up.

## API endpoints actually consumed

Every endpoint goes through generated React-Query hooks from `@app/sdk` (orval emit). Access token injected by `lib/sdk.ts` `configureSdk({ getAccessToken })`. Offline cache via `@tanstack/query-async-storage-persister` (24h TTL).

- `POST /auth/login` — `useAuthControllerLogin` — `login.tsx`
- `POST /auth/register` — `useAuthControllerRegister` — `register.tsx`
- `POST /auth/magic-link/request` — `useAuthControllerMagicLinkRequest` — `auth/magic-link.tsx`
- `POST /auth/magic-link/consume` — `useAuthControllerMagicLinkConsume` — `auth/magic-link/[token].tsx`
- `GET /auth/me` — `useAuthControllerMe` — `profile.tsx`
- `GET /trips` — `useTripControllerList` — `(tabs)/trips.tsx`
- `GET /trips/{id}` — `useTripControllerGetOne` — `trips/[id].tsx`
- `GET /trips/{id}/itinerary` — `useTripControllerGetItinerary` — `trips/[id].tsx`
- `GET /notifications/mine` — `useNotificationsControllerListMine` — `(tabs)/inbox.tsx`
- `PATCH /notifications/{id}/archive` — `useNotificationsControllerArchive` — `(tabs)/inbox.tsx`
- `GET /memory-books/{id}` — `useMemoryBookControllerGetOne` — `memory-books/[id].tsx`

**No refresh-token call.** **No device-register-for-push call.** **No location-aware queries.** No `apiFetch` direct calls, no axios — only generated hooks (good).

## Token storage — current state

```ts
// apps/mobile/lib/sdk.ts (paraphrased)
let memoryToken: string | null = null; // ✅ access token in memory at runtime
await AsyncStorage.setItem(KEY, token); // ⚠️ persists UNENCRYPTED across reboots
```

CLAUDE.md rule 12: _"never store tokens in `localStorage`. Access tokens live in memory; refresh tokens live only in httpOnly cookies."_

- Mobile can't use httpOnly cookies (no http client honors them on RN).
- Mobile **does** keep the access token in memory while the app runs (compliant).
- Mobile **does not** encrypt the token at rest (non-compliant).
- Mobile **has no refresh-token rotation** — on 401 the user must re-login manually.

D1 closes both gaps: swap to `expo-secure-store` + implement refresh-on-401 (API already issues refresh tokens — `apps/api/src/modules/identity/`).
