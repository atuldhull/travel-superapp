# Round AP progress — canvas-shared behavioural specs (workflow-driven)

> Round AP closes the canvas-shared behavioural-spec gap that Round
> AO opened. After AO, 5 of the 35 shared modules had own
> behavioural specs (plus shape-gate + invariants). Round AP adds
> 7 more in one workflow pass — every high-value state-modelling
> module in the package now has its math pinned inside the package
> itself, so the Phase 4 native port re-export is a direct contract
> handoff.

## Workflow

Round AP was generated by a single Workflow tool invocation —
`round-ap-canvas-shared-specs` — that pipelined two stages over the
7 target modules in parallel:

1. **Read stage (7 agents)** — each agent read one source file and
   returned its content verbatim.
2. **Generate stage (7 agents)** — each agent took its source and
   emitted a structured `{slug, specContent, testCount,
commitSubject, commitBody}` object via a JSON-schema-enforced
   StructuredOutput call.

Main loop then: wrote each spec file, ran jest --testPathPattern
on it, fixed any failures (one mojibake patch on `mirror-globe`),
and committed one per slice.

## What each slice pins

### AE497 — continuum-state (32 tests)

The cross-device handoff URL contract. `buildContinuumUrl`
pathname normalisation (leading-slash injection, trailing-slash
trim, root preservation), origin handling, extras URI-encoding,
marker-append order, and the rule that extras keys cannot shadow
the `aether-continuum=1` marker. `parseContinuumUrl` round-trip
through `buildContinuumUrl`, marker-only input, absolute URL
pathname extraction, malformed + non-string input. `isContinuumUrl`
marker probe; `continuumSigilSeed` device-identity stability;
`CONTINUUM_QUERY_KEY` value pinned.

### AE498 — weather-simulation (44 tests)

`weatherForSlugMonth` across every curated belt (monsoon coast,
high-altitude storm window, Darjeeling extended monsoon, Hampi
Deccan, desert clear year-round), case-insensitive slug
normalisation, storm-wins-over-rain precedence, unknown / empty /
non-string slug fallback. `simulatedWeatherFor` Date + ISO string
parsing + NaN guard. `weatherHasParticles` /
`weatherStreakIntensity` / `weatherStreakCount` union FSM with
each switch arm locked at its tuned numeric value (0/1/1.6,
0/400/700).

### AE499 — lumen-museum (23 tests)

`DEFAULT_MUSEUM_ARC` frozen tunables + `museumArcPositions`
empty-Map guards (null focus / missing focused id). Asserts the
focused plane is always echoed back, X-axis sort drives arc
placement, id tie-break keeps positions stable. Per-plane math:
singleton other-plane at angle=0, +/- radius endpoints, vertical
compression bounds, depthOffset along -Z. `resolveMuseumTarget`
three-branch fallback table.

### AE500 — vault-sample-prices (19 tests)

Catalogue structural shape (id + label + INR + integer minor
amount + 7-entry history), deep-freeze guarantee, unique ids,
non-empty. `SAMPLE_VAULT_MIN_AMOUNT` / `MAX_AMOUNT` true
min/max over the catalogue + bracket invariant. Canonical
fixtures (Leh stay, Jaipur return) pinned so the AE414 demo
cannot silently drift.

### AE501 — genie-recorder (46 tests)

Six-state recorder status union + the 60s hard cap + 100ms tick
constants + frozen mime preference list. Branch coverage:
`pickAudioMimeType` walks preferences and falls through to null;
`formatRecordingDuration` collapses Infinity / NaN / negatives to
`0:00`, pads single-digit seconds; `shouldAutoStop` boundary at
`>= MAX_RECORDING_MS`; `recorderStatusLabel` embeds live duration
on recording + stopped; `isRecorderBusy` and `canStartRecording`
partition the six-state union with no overlap; `genieMimeExtension`
normalises codec params, trims whitespace, falls back to webm for
empty / null / undefined / unknown.

### AE502 — mirror-globe (47 tests)

Globe lat/lng projection, SOS dot sizing, scam cluster sqrt
scaling, audit-river TTL filter + y-progress interpolation, glyph
colour + symbol tables, admin/superadmin viewer gate. Branches:
non-finite inputs, clamped severity ends, empty/positive/zero
report counts, before/at/after TTL elapsed boundaries, every
kind cell of the colour + symbol switches.

### AE503 — echo-feed (41 tests)

Swipe-direction decoder (noise floor, axis tiebreak, non-finite +
NaN guards), direction-to-action mapping, `nextEchoIndex`
clamping at both ends. `boostHexColor` saturation behaviour: null
fallback to Warm Italian terracotta, malformed hex pass-through,
all-zero short-circuit, factor cap, 3-channel boost,
case-insensitive parse. `echoPaletteFromDominantColor` 5-slot
tuple shape + baseline preservation. `formatEchoPostedAt` six-stage
relative-time table (just now / m / h / d / w / locale fallback).

## Recovery from one workflow-output mojibake

One returned spec (`mirror-globe`) had three Unicode glyphs
(`◆ • ⚠ ◉ ·`) double-encoded as Latin-1 mojibake in the JSON
payload (the agent saw `◆` but the JSON-on-disk had `â—†`). Main
loop noticed two failing assertions on first jest run, then
rewrote the affected `describe` block with `[char]0xNNNN`
expansion in PowerShell so the file landed with the right code
points. No regressions in the patched block; suite went 45/47 →
47/47.

This is the second mojibake recovery in this rolling project (the
prior was AE473 → reauthored as AE483 last round) — both confirm
the hybrid pattern: agents propose, main loop verifies and patches.

## Coverage map after Round AP

35 canvas-shared modules → 12 have own behavioural specs inside
the package (was 5 before AP, was 0 before AO). The remaining
23 break down as:

- **Already adequately covered** by the canvas-shared `invariants.spec.ts`
  (AE489 — sphere-surface, unit-vector, monotonicity bounds): compass-rose,
  vault-glyph-positions, lifecycle-progress, pulse-breathing, echo-layout,
  now-card-content. Behaviour pinned at law-level; per-branch coverage isn't
  needed for the Phase 4 port.
- **Web-side specs already pin the consumer surface** (apps/web/test/lib/...):
  atlas-orbs, lumen-cloud, lumen-strategies, lumen-selection, lumen-keyboard,
  destination-coords, genie-particles, genie-camera, vault-glyphs,
  mirror-investigate, live-trip-watch, now-card-lifecycle, upcoming-trip,
  continuum-sigil, continuum-landing, lifecycle-camera. The Phase 4 port
  will re-verify by running canvas-shared invariants + the apps/web suite.

That leaves ~5-7 helper-style modules without own behavioural coverage —
candidates for a future Round AQ if it lands before Phase 4: lifecycle-camera
(deeper than the invariant), continuum-sigil (deterministic seed math), and
the lumen-\* family (state interactions beyond the invariants).
