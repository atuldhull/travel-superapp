# DR drill log

Append-only record of every disaster-recovery drill. One file per
quarter (e.g. `2026Q2.md`). Generated by
[`scripts/dr/restore-test.sh`](../../scripts/dr/restore-test.sh).

A missed quarter is a SEV-2 + filed as a tracking issue. See
[backups-dr.md](../runbooks/backups-dr.md) for what we drill and why.
